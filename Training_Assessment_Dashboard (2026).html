How to add trainings: click Add training file (or drop files here) for each training sheet — new or previous. Each file is added to what is already loaded, and the page remembers it in this browser, so next time you open the file your trainings are still there. Loading the same training again replaces its old rows instead of doubling them. One sheet can also hold several trainings if it has a Training Name column. The sheet needs these column headings in any order: Employee ID Employee Name Department Location Attended (Yes/No) Correct Answers Total Questions — and Training Name and Training Date (if Training Name is missing, the file name is used as the training name). Result rule: Attended = No → Not attended; otherwise score ≥ pass mark → Pass, else Fail. Loading Excel needs an internet connection the first time the page opens (for the Excel reader); CSV files always work.
